T Help Desk Ticketing System
For my project, I plan on making an IT Help Desk Ticketing System. The idea is to make a program where someone can report a computer or technology problem they are having. Instead of emailing the IT person or trying to find them in person, they can put the problem into the system and make a ticket. The IT person can then see the ticket and keep track of it until the problem is fixed.
There will be two types of users for my system. One will be the person who needs help and the other will be the IT administrator. A regular user will be able to put in their name, explain the problem they are having, and submit a ticket. The IT administrator will be able to see the tickets that were sent in and work on them. They will also be able to change the status of a ticket depending on whether it is new, being worked on, or already fixed.
For the user interface, I plan on using JavaFX. This will allow me to make things like buttons, text boxes, and different screens for the program. For example, the user could have a screen where they type in their name and the problem they are having and then click a button to submit the ticket. The IT side would have a screen where they can see the tickets and update them.
For the coding part, I plan on using Java because that is the programming language I am most familiar with. I have used Java in my previous classes, so I want to use what I already know as the starting point for this project. I also plan on learning how to use JavaFX to make the user interface. I have not worked with JavaFX before, so that will be something new for me to learn while working on the project.
I am also going to try using SQLite for the database. I haven’t used SQLite before so this part will be new to me. I need some type of database because when someone puts in a ticket I need the program to remember it. I want it to save stuff like who put the ticket in, what the problem was, and if the problem has been fixed yet.
What I want to have when I’m done is a simple help desk program that actually works. I picked a help desk because it relates to the type of IT work I am interested in. I already know some Java from my other classes, but the database and JavaFX side will be new for me. So I will be learning those parts as I go through the project.
